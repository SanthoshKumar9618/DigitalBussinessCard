========================================
BACKEND SETUP INSTRUCTIONS
========================================

This document explains how to set up and run the backend server.

QUICK START:
------------
1. Run setup.bat (first time only)
2. Run run.bat (every time you want to start the server)

DETAILED STEPS:
--------------

STEP 1: Initial Setup (One-time)
---------------------------------
1. Open Command Prompt or PowerShell in the backend folder
2. Run: setup.bat
   OR manually:
   - python -m venv venv
   - venv\Scripts\activate
   - pip install -r requirements.txt

STEP 2: Environment Variables
------------------------------
Create a .env file in the backend folder with the following variables:

POSTGRES_USER=your_db_user
POSTGRES_PASSWORD=your_db_password
POSTGRES_HOST=localhost
POSTGRES_PORT=5432
POSTGRES_DB=your_database_name
POSTGRES_DSN=postgresql://user:password@host:port/dbname

JWT_SECRET=your_secret_key_here
JWT_ALGORITHM=HS256
JWT_ACCESS_TOKEN_EXPIRE_MINUTES=10080
JWT_REFRESH_TOKEN_EXPIRE_DAYS=30

smtp_email=your_email@gmail.com
smtp_password=your_app_password
smtp_server=smtp.gmail.com
smtp_port=587

BACKEND_CORS_ORIGINS=["http://localhost:3000","http://localhost:8081"]

STEP 3: Database Setup
----------------------
1. Make sure PostgreSQL is running
2. Create your database
3. Run migrations:
   - alembic upgrade head

STEP 4: Run the Server
---------------------
1. Run: run.bat
   OR manually:
   - venv\Scripts\activate
   - uvicorn app.main:app --reload

The server will start at: http://localhost:8000

TROUBLESHOOTING:
---------------

Problem: ModuleNotFoundError
Solution: Run setup.bat to install all dependencies

Problem: Database connection error
Solution: Check your .env file and ensure PostgreSQL is running

Problem: Port already in use
Solution: Change the port in run.bat or kill the process using port 8000

Problem: UnicodeEncodeError
Solution: This has been fixed in the code. Make sure you have the latest version.

MANUAL COMMANDS:
---------------
# Activate virtual environment
venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt

# Run server
uvicorn app.main:app --reload

# Run migrations
alembic upgrade head

# Create new migration
alembic revision --autogenerate -m "description"
