Gmail
  1. Open Gmail on a computer → ⚙️ Settings → See all settings.
  2. Under Signature, create a new one and paste.
  3. Scroll down and click Save Changes.
Outlook
  1. Settings → Mail → Compose and reply (or File → Options → Mail → Signatures).
  2. Create a new signature, paste, then save.
Apple Mail (Mac / iPhone)
  1. Mac: Mail → Settings → Signatures → +, then paste.
  2. iPhone: Settings → Apps → Mail → Signature, then paste.
